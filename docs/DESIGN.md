# Design direction

## Product

좋아하는 장소를 모아 하루를 구성하고 다음에도 꺼내 쓰는 보관함에 초점을 둡니다. 커플 용도로 시작하지만 친구·가족·개인 나들이도 자연스럽게 사용할 수 있게 장식·문구를 절제합니다.

## References reviewed

- [Wanderlog](https://wanderlog.com/): 일정과 지도 동시 보기, 장소 카드, 이동 구간, 계획 미리보기. 공식 홈페이지와 화면 이미지를 확인했습니다.
- [Airbnb wishlists](https://www.airbnb.com/help/article/1236): 보관·즐겨찾기·다시 꺼내 쓰는 목록의 사용 흐름을 참고했습니다.
- [Notion projects](https://www.notion.com/product/projects): 작업 공간·컬렉션의 단순한 정보 구성을 참고했습니다.

서비스 레이아웃·브랜드·이미지를 복제하지 않았습니다. 초기 버전에는 계정·공동편집을 지원한다고 표시하지 않습니다.

## Visual language

- 아이보리 바탕, 포레스트 그린 행동 버튼, 연한 세이지 표면.
- 기본 커버는 모든 장소를 포함하는 2D 정지 지도입니다. 실제 지도를 한 공용 렌더러에서 순차 생성하고 최대 32개 결과를 메모리에 재사용합니다. 화면에서 멀어진 카드는 중단하고 대기열을 제한합니다. 지도 실패 시에만 좌표 동선 SVG로 대체합니다. 위치가 없는 구간을 건너뛰어 연결하지 않습니다.
- 사진은 사용자가 직접 추가했을 때만 표시하고, 삭제하면 즉시 동선으로 복원합니다. 기존 분위기 사진 파일은 제거했습니다.
- 데스크톱: 보관함 탐색 후 장소 목록과 지도 나란히 표시.
- 모바일: 기존 코스는 전체 동선 지도부터 시작하고 ‘일정 보기’로 전환합니다. 새 빈 코스는 편집부터 시작합니다. 데스크톱은 일정과 전체 지도를 나란히 보여줍니다.
- 지도 터치: 한 손가락 이동, 두 손가락 확대·축소·회전, 두 손가락을 나란히 위아래로 움직여 기울이기. 확대 버튼·나침반·전체 코스·2D/3D 전환도 제공합니다. 직접 조작하면 자동 투어를 중지하고 실제 기울기를 UI에 반영합니다. 실제 기기 멀티터치는 별도 검증 대상입니다.
- 확대는 동네 맥락이 남는 수준. 지도 기반 입체 건물과 실사 영상을 명확히 구분.
- 모달은 native dialog로 키보드 포커스를 가둠. 장소 순서는 드래그 외 위·아래 버튼도 지원.
- reduced-motion에서는 카메라 이동 시간을 0으로 하고 CSS 전환·애니메이션을 중지.
- 사용자 피드백에 따라 홈 홍보 배너·영문 장식·카드 설명·반복 안내·중복 생성 버튼을 제거했습니다. 동선·코스명·장소 수·시간을 기본으로 노출하고, 지도 설명은 정보 버튼 안에, 상세 안내는 설정 안에 둡니다.

## Next decisions

2. 실제 도보·차량 경로 API와 다른 지도에 결과를 표시할 권리.
3. V-World 등 실사 3D: 서울·경기 실제 코스 지점에서 품질·속도·이용 조건 검증.
4. 날씨·영업시간·휴무의 데이터 출처와 마지막 확인 시각. 자동으로 확정 일정을 바꾸지 않기.
5. 배포 후 계정·기기 동기화·둘이 편집·공유 링크 회수. 사본 URL 공유와 구분.
6. 공개 서비스 단계에서 접근성 대비·실제 iPhone/Android·지도 데이터 요청량 점검.

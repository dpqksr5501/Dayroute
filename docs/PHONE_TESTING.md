# Android에서 테스트

## Vercel HTTPS 주소로 접속

1. 배포 완료 후 안내된 **고정 Production 주소**를 Android Chrome에서 엽니다. USB, 같은 Wi-Fi, PC 실행은 필요하지 않습니다.
2. 자주 사용하면 Chrome 메뉴의 **홈 화면에 추가 / 앱 설치**를 선택합니다. 메뉴 이름은 Chrome 버전에 따라 다를 수 있습니다.
3. 수정 사항은 GitHub에 push하면 연결된 Vercel 프로젝트가 다시 빌드합니다. 같은 고정 주소를 계속 사용하세요. 새 버전 안내가 뜨면 저장 후 업데이트합니다.
4. 코스·직접 올린 사진은 여전히 **그 기기의 브라우저**에 저장됩니다. PC에서 만든 코스를 옮기려면 전체 백업 파일을 폰으로 보내고 설정 → 파일 가져오기를 사용하세요. 자동 계정 동기화는 없습니다.

## 확인할 동작

- 보관함: 사진이 없는 카드는 **모든 지점이 보이는 정지 지도**. 카드 위에서는 지도 제스처를 받지 않습니다.
- 코스 진입: 모바일은 모든 장소가 보이는 지도부터 시작합니다. **일정 보기**에서 장소·사진을 편집합니다. 새 빈 코스는 편집 화면부터 시작합니다.
- 지도: 한 손가락 이동, 두 손가락 핀치 확대·축소, 회전, 두 손가락을 나란히 위아래로 움직여 기울이기.
- 장소 번호 선택 → 해당 장소로 이동. **전체** → 모든 위치가 보이는 2D 개요로 복귀. 같은 장소를 다시 눌러도 이동하는지 확인합니다.
- 자동 둘러보기 중 직접 지도를 만지면 투어가 멈춥니다. 확대 버튼과 2D/3D 버튼도 사용할 수 있습니다.
- 일정 보기 → 사진 추가 → 새로고침 후 유지 → 사진 삭제 → 기본 지도 커버로 복귀.
- 사진이 포함된 코스 파일을 내보내고 다시 가져왔을 때 내용과 사진이 함께 복원되는지 확인합니다.

## 문제를 발견했을 때

어느 화면·어느 버튼에서 발생했는지, 재현 순서, Android/Chrome 버전, 스크린샷을 함께 알려주세요. 설정과 데이터에서 앱 버전을 확인할 수 있습니다.

Vercel의 서버/빌드 로그만으로 휴대폰 브라우저 안의 JavaScript 오류를 모두 볼 수 있는 것은 아닙니다. 상세 콘솔이 필요할 때는 PC Chrome의 [Android 원격 디버깅](https://developer.chrome.com/docs/devtools/remote-debugging)을 사용합니다. 단순 화면·터치·저장 테스트에는 USB가 필요 없습니다.

Production과 매번 달라지는 Preview URL, Chrome 일반 탭과 다른 브라우저는 보관함이 다를 수 있습니다. 테스트 데이터가 유지돼야 하면 고정 주소와 같은 브라우저를 사용하세요.

## 배포 조건

현재 개인·비상업 테스트는 Vercel Hobby 범위로 구성합니다. 무료 제공량에는 한도가 있으며, 상업 운영 단계에서는 [Vercel 요금제 조건](https://vercel.com/docs/plans/hobby)을 다시 확인해야 합니다. 유료 지도 API, DB, 사진 업로드 서버는 추가하지 않았습니다.
